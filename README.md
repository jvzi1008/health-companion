# 健康伴侣（Health Companion）— 适老化健康助手

给刚退休、文化程度不高的城市中老年人，一个会主动关心你、陪你说话、帮你管健康的 AI 小管家。

## 目录结构

| 路径 | 说明 |
|---|---|
| `docs/framework.md` | 产品与技术框架（v0.2 对话优先版），含信任阶梯、主次架构、AI 设计、合规与风险 |
| `prototype/index.html` | 交互原型（对话优先，浏览器直接打开） |
| `server/server.js` | AI 代理服务（零依赖 Node，保管 API Key、转发对话与语音） |
| `server/.env.example` | API Key 配置模板（复制为 `.env` 使用） |
| `start.bat` | 一键启动 AI 代理服务 |

## 快速开始

### 第 1 步：配置 API Key（想听"桃子"声线、真实 AI 回复必须有）

复制 `server\.env.example` 为 `server\.env`，填入至少一个 Key：

| 想用 | 申请地址 | 填入 |
|---|---|---|
| 豆包对话 + 桃子声线 + 拍照识别 | https://console.volcengine.com/ark | `DOUBAO_API_KEY=` |
| DeepSeek 对话 | https://platform.deepseek.com | `DEEPSEEK_API_KEY=` |

默认音色为豆包"甜美桃子 2.0"（`zh_female_tianmeitaozi_uranus_bigtts`），需在方舟开通语音合成模型服务；若未开通 2.0，可改用 1.0 模型 + 灿灿声线（见 `.env.example` 注释）。

### 第 2 步：启动代理服务

双击 `start.bat`，或手动执行：

```
cd server
node server.js
```

看到 `健康伴侣 AI 代理已启动: http://localhost:3001` 即成功。

### 第 3 步：打开原型

浏览器打开 `prototype/index.html`（推荐 Chrome/Edge）。顶部提示条会显示连接状态：
- `已连接 AI 服务：豆包、DeepSeek` → 真实回复中
- `已连接代理，但未配置 API Key` → 对话为演示回复，语音自动降级

右上角菜单 → 设置 里可切换：AI 引擎（豆包 / DeepSeek / 演示）、AI 声音（桃子 / 灿灿 / 晓晓 / 浏览器）。

## 原型功能

- 对话为主界面：大圆钮"按住说话" + 快捷回复 + 打字兜底
- AI 人设开场（分时间段问候）+ 用药提醒卡片 + 30 秒健康小课堂
- 症状分级（红/黄/绿）：命中危险词 → 红色应急流程；一般不适 → 黄色建议就医；普通 → 绿色观察
- SOS 按钮：防误触二次确认 → 模拟自动通知家人并附定位/病历/过敏史
- 拍照/相册：拍药盒（AI 识别药名并录入用药提醒）、体检报告（读出关键指标）、皮肤/伤口（初步判断）。有豆包 Key 时用视觉模型真识别，否则为演示回复
- 家属监护入口、健康档案、急救手册、设置（称呼/字号/语音）

## 说明

- **代理服务是必须的**：浏览器不能直接带 API Key 调大模型（密钥会暴露、且有跨域限制），一切请求都走 `server.js` 转发。
- **语音降级顺序**：豆包 TTS（桃子）→ 无 Key 或失败时 Edge 晓晓 → 仍失败时浏览器内置声音。
- 原型尚未做正式医疗免责措辞，仅为演示用途。
